# Publicar el Panel de gestión BIOFILE

1. Cree un repositorio separado llamado `panel-gestion-biofile-vip`.
2. No use el repositorio `brigadas-salud-vip`, porque ese controla el formulario público de Brigadas.
3. Suba todos los archivos de esta carpeta, con `index.html` en la raíz.
4. En Netlify abra el sitio actual del panel y vincúlelo al nuevo repositorio. Si aún no existe un sitio para el panel, cree uno nuevo desde Git.
5. Configure rama `main`, comando de compilación vacío y directorio de publicación `.`.
6. Verifique que el despliegue aparezca como `Published`.
7. Abra un paciente y confirme que la tarjeta “Exámenes asociados a esta cédula” muestre la información del Sheet Maestro.
